# Public Portfolio Engineering Rules

- Correctness, reproducibility, restraint, and honest claims matter more than feature count.
- Protect behavioral changes with deterministic, network-free tests.
- Do not invent capabilities, adoption, benchmarks, or screenshots.
- Keep network access behind explicit timeouts, identification, rate limits, and actionable errors.
- Do not commit personal databases, caches, credentials, or downloaded models.
- Keep optional embedding features separate from the basic research workflow.
- Run tests and report exact verification commands before claiming completion.
